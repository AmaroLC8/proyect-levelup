# Level-Up Gamer - Proyecto Frontend 🚀

Este proyecto es una aplicación web desarrollada para la asignatura **Desarrollo Fullstack II (DSY1104)**[cite: 2]. Consiste en la maquetación y desarrollo frontend de la tienda online "Level-Up Gamer", enfocado en la cultura gamer[cite: 2]. Incluye sistema de registro de usuarios, catálogo de productos, carrito de compras y un panel de administración para la gestión interna de la tienda.

## 🛠️ Tecnologías y Herramientas Utilizadas
* **HTML5:** Para la estructura semántica y las múltiples vistas del sitio[cite: 2].
* **CSS3 y Bootstrap:** Para los estilos personalizados y un diseño 100% responsivo[cite: 2].
* **JavaScript:** Para la lógica de validación de los formularios y la operatividad de las interfaces[cite: 2].

## 📂 Estructura del Proyecto
El proyecto está organizado de la siguiente manera para mantener un código limpio y escalable[cite: 1]:

* `index.html`: Página principal de la tienda[cite: 1].
* `registro.html` / `login.html`: Vistas para la creación de cuentas e inicio de sesión[cite: 1].
* `catalogo.html` / `producto-detalle.html`: Vistas para explorar los productos disponibles[cite: 1].
* `carrito.html`: Interfaz para la gestión del carrito de compras[cite: 1].
* `contacto.html`: Formulario para soporte técnico[cite: 1].
* `admin/`: Directorio que contiene las vistas de administración (gestión de productos y usuarios)[cite: 1].
* `assets/`: Directorio principal de recursos visuales, que contiene la hoja de estilos (`style.css`) y las imágenes del proyecto (`img/`)[cite: 1].
* **Archivos `.js`**: La lógica está modularizada por vista (`app.js`, `registro.js`, `login.js`, `carrito.js`, etc.)[cite: 1].

## 💻 Cómo ejecutar el proyecto
1. Clona o descarga este repositorio en tu computador[cite: 2].
2. Abre la carpeta del proyecto[cite: 2].
3. Haz doble clic en el archivo `index.html` para abrirlo directamente en tu navegador web de preferencia (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.)[cite: 2].
